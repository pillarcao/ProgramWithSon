# 🎈 ProgramWithSon - 和儿子一起学编程
> 适合小学3年级（8-9岁）孩子的趣味Python编程案例集，边玩边学，寓教于乐

## 📚 项目介绍
这是我和儿子一起学习编程的代码仓库，所有案例都遵循：
- ✅ **简单易懂**：代码量少，注释详细，没有复杂概念
- ✅ **趣味十足**：都是小游戏、小工具，孩子能看到即时反馈
- ✅ **循序渐进**：从入门到进阶，难度逐步提升
- ✅ **实用好玩**：写的代码可以直接用，或者和家人一起玩

## 🎯 难度分级
| 难度 | 级别 | 适合人群 | 知识点 |
|------|------|----------|--------|
| ★ | 入门级 | 刚接触编程，会基本的打字 | 变量、输入输出、条件判断、循环 |
| ★★ | 进阶级 | 有基础，知道基本语法 | 函数、模块、异常处理 |
| ★★★ | 挑战级 | 熟练基础，想做更复杂的项目 | 面向对象、游戏开发、第三方库使用 |

## 📁 案例目录
### 🌟 入门级 (入门必学)
1. **[猜数字游戏](./01_入门级/01_猜数字游戏.py)** - 和爸爸对战，猜1-100的随机数字
2. **[小画家画图](./01_入门级/02_小画家画图.py)** - 用turtle库画小房子、小花、小汽车
3. **[摇骰子对战](./01_入门级/03_摇骰子对战.py)** - 家庭摇骰子比赛，看谁的点数大
4. **[石头剪刀布](./01_入门级/04_石头剪刀布.py)** - 经典的石头剪刀布对战游戏

### 🚀 进阶级 (有基础后学)
1. **[简易计算器](./02_进阶级/01_简易计算器.py)** - 自己写的计算器，用来验算数学作业
2. **[倒计时闹钟](./02_进阶级/02_倒计时闹钟.py)** - 写作业、玩游戏计时工具，实用又好玩
3. **[九九乘法表生成器](./02_进阶级/03_九九乘法表生成器.py)** - 自动生成九九乘法表，还能随机出题练习
4. **[二维码生成器](./02_进阶级/04_二维码生成器.py)** - 把文字、网址变成二维码，好玩又实用

### 🔥 挑战级 (兴趣进阶)
1. **[简易贪吃蛇](./03_挑战级/01_简易贪吃蛇.py)** - 经典贪吃蛇小游戏，用pygame实现
2. **[打字练习游戏](./03_挑战级/02_打字练习游戏.py)** - 练习打字速度的小游戏，边玩边提高打字水平

## 🛠️ 环境准备
1. 安装Python 3.8+：https://www.python.org/downloads/
2. 安装需要的库（部分案例需要）：
   ```bash
   # 贪吃蛇游戏需要pygame
   pip install pygame
   
   # 二维码生成器需要qrcode
   pip install qrcode[pil]
   ```

## 🎮 怎么玩
1. 找到对应难度的`.py`文件
2. 跟着代码敲一遍，或者直接运行看看效果
3. 尝试修改代码里的参数，比如改变颜色、调整速度、增加功能
4. 发挥自己的创意，写出自己的小游戏！

## 💡 学习建议
1. **先运行再理解**：先把代码跑起来看到效果，再慢慢理解每一行是做什么的
2. **多改多试**：不要怕写错，大胆修改参数，看看会发生什么变化
3. **边玩边学**：编程不是枯燥的写代码，是创造自己的游戏和工具
4. **一起玩**：家长陪着孩子一起写，一起玩，孩子会更有兴趣
